# Daylist v1.2.0 - Sign up for a private workspace

- Sign up from the login page and get your own private tasks, folders, and notes.
- Usernames: up to 15 letters and numbers. Passwords: at least 14 characters and one number.

## Upgrade

Set your Compose image to `ghcr.io/charya-s/daylist:1.2.0`, keep your existing settings and data volume, then run:

```sh
docker compose pull
docker compose up -d
```
