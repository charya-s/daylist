# Daylist v1.2.0 - Sign up for a private workspace

Daylist now lets people create an account from the sign-in page. Each account has its own tasks, folders, notes, and subtasks, so several people can use the same installation independently.

## Added

- **Self-service sign-up:** click **Create an account**, choose a username and password, and start using Daylist immediately. New users are signed in automatically and receive a regular account without administrator privileges.
- **Simple account rules:** new usernames contain 1-15 letters or numbers. Passwords contain at least 14 characters and at least one number. The form displays the same rules that the server enforces.
- **Account validation:** duplicate usernames, including names that differ only by letter case, are rejected. Passwords must match their confirmation.
- **Registration protection:** sign-up has its own limit of ten attempts per minute per app instance, separate from the existing sign-in limit.

## Existing installations

Existing accounts and task data continue to work. Existing usernames can still sign in even if they do not meet the new registration rules. No additional database migrations are required for these features.

Registration is open to anyone who can reach the app. Email addresses are not collected, and email password recovery is not included. A server administrator can reset a forgotten password with:

```sh
docker compose exec app python manage.py changepassword USERNAME
```

## Upgrade

Set your Compose image to `ghcr.io/charya-s/daylist:1.2.0`, keep your current secret, port mapping, and data volume, then run:

```sh
docker compose pull
docker compose up -d
```

The attached `compose.yaml` is also available for a fresh installation. See the [README](https://github.com/charya-s/daylist#readme) for setup.
