# Daylist v1.4.1

- Date selections save instantly for tasks and subtasks.
- Edit task and subtask names in place; Enter or clicking away saves, and Escape cancels.
- Find finished tasks in Completed above Trash, and uncheck them to reopen.

## Upgrade

Use `ghcr.io/charya-s/daylist:1.4.1` or keep `:latest`, then run:

```sh
docker compose pull
docker compose up -d
```

Keep your existing settings and data volume.
