# Daylist v1.1.0 - Smoother editing and navigation

Daylist now saves task changes and switches views without reloading the whole page. Folder names can be edited directly in the heading.

## Added and improved

- **Rename folders in place:** click a folder title, type a name, and press Enter or click away to save. Escape cancels. A successful rename no longer leaves the title highlighted.
- **Background saves:** add, edit, complete, reopen, reschedule, and delete tasks and subtasks without a full page reload. Notes and priority flags use the same background saving flow.
- **Seamless navigation:** switch between All, Today, folders, and task details without reloading. Browser Back and Forward continue to work.
- **Preserved work:** unfinished edits are kept during background saves and restored when returning to a view. Scroll position and collapsed task groups are preserved where applicable.
- **Visible failure feedback:** failed requests keep your edits available and show a message instead of silently discarding them.
- **Simpler self-hosting:** Docker publishes the app on the server's network interfaces by default, and hostname configuration is optional. The container is named `daylist`.

## Upgrade

Use `ghcr.io/charya-s/daylist:1.1.0`, keeping your existing secret, port mapping, and data volume, then run:

```sh
docker compose pull
docker compose up -d
```

If your existing `.env` restricts `APP_HOSTS`, remove that entry or use `APP_HOSTS=*` to accept any hostname. The attached Compose file publishes port 8000; retain your own port mapping if you use another port.

## Validation

Browser checks covered inline editing, task and subtask actions, notes, dates, failed saves, editing during a save, mobile layout, navigation history, and rapid list switching. Docker installation and migration checks passed.
