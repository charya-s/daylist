# Daylist v1.1.0 - Smoother editing and navigation

- Rename folders by clicking their title.
- Save task changes and switch lists without page reloads.
- Keep unfinished edits and scroll position during updates.
- Simpler LAN setup and a fixed container name: `daylist`.

## Upgrade

Set your Compose image to `ghcr.io/charya-s/daylist:1.1.0`, keep your existing settings and data volume, then run:

```sh
docker compose pull
docker compose up -d
```
