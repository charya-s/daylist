# Daylist v1.0.0 - First Docker release

- All, Today, and custom folders, with due dates, notes, priority flags, and subtasks.
- Mobile layouts, light/dark themes, and persistent task storage.
- Docker images for amd64 and arm64.

## Install

Download the attached `compose.yaml` and follow the [setup instructions](https://github.com/charya-s/daylist/tree/v1.0.0#readme).
