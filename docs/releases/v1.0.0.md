# Daylist v1.0.0 - First Docker release

The first versioned Docker release of Daylist, a compact, self-hosted task workspace inspired by TickTick.

## Included

- **Task views:** All, Today, and custom folders, with tasks grouped by due date and completion status.
- **Task details:** editable titles, notes, priority flags, and subtasks with independent completion and optional due dates.
- **Date shortcuts:** Today, Tomorrow, Next week, and No date, plus date suggestions in the quick-add field.
- **Responsive appearance:** desktop and mobile layouts, light and dark themes, and timezone-aware Today filtering.
- **Private sign-in:** Django sessions, CSRF protection, Argon2id password hashing, and a sign-in attempt limit. Accounts are created from the server in this release.
- **Self-hosted storage:** SQLite in a persistent Docker volume, with backup and reverse proxy instructions.
- **Versioned installation:** Docker images for Linux amd64 and arm64, with an attached image-based Compose file.

## Install

Download the attached `compose.yaml`, configure `DJANGO_SECRET_KEY` in `.env`, start the app with `docker compose up -d`, and create an account with:

```sh
docker compose exec app python manage.py createsuperuser
```

See the [README](https://github.com/charya-s/daylist/tree/v1.0.0#readme) for the setup instructions for this version.
