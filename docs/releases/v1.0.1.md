# Daylist v1.0.1 - Easier reverse proxy setup

- HTTPS redirects are handled by your reverse proxy; `LOCAL_HTTP` is no longer needed.
- Improved startup checks and deployment instructions.

## Upgrade

Set your Compose image to `ghcr.io/charya-s/daylist:1.0.1`, keep your existing settings and data volume, then run:

```sh
docker compose pull
docker compose up -d
```
