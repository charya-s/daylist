# Daylist v1.0.1 - Easier reverse proxy setup

This maintenance release simplifies HTTP and HTTPS configuration and improves the release installation checks.

## Changed

- **HTTPS policy belongs to the reverse proxy:** configure TLS, HTTP redirects, and HSTS in your proxy. Daylist no longer needs the `LOCAL_HTTP` switch.
- **Secure cookies follow the connection:** session and CSRF cookies are marked Secure when the request is recognized as HTTPS through the trusted proxy header.
- **Clearer deployment instructions:** the README explains local access, proxy configuration, and keeping the backend port private, and includes light and dark screenshots.
- **More reliable release checks:** the installer check retries while the app starts. Publishing can also be started manually for an existing tag.

## Upgrade

Use `ghcr.io/charya-s/daylist:1.0.1` and keep the same data volume and secret. Configure HTTPS and redirects in your reverse proxy, and remove the old `LOCAL_HTTP` setting if present. Run `docker compose pull` followed by `docker compose up -d`.

The attached `compose.yaml` is for installation. See the [README](https://github.com/charya-s/daylist#readme) for deployment details.
