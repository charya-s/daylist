# Daylist v1.4.0

- Change existing folder colors instantly from the folder menu.
- Use the task date picker and shortcuts for subtasks too.
- Restore deleted tasks, subtasks, and folders from Trash, or delete them forever.
- Change your password through the sidebar profile icon.
- Cleaner task details with compact repeat settings beside the date and folder.

## Upgrade

Use `ghcr.io/charya-s/daylist:1.4.0` or keep `:latest`, then run:

```sh
docker compose pull
docker compose up -d
```

Keep your existing settings and data volume. The database update runs at startup.
