# Daylist v1.3.0 - Matrix, search, and repeating tasks

- Eisenhower Matrix with automatic sorting, drag-and-drop placement, and folder filters.
- Search task titles, notes, subtasks, and folder names without reloading.
- Daily, weekly, monthly, and yearly repeats, with custom intervals and fresh subtasks for each occurrence.

## Upgrade

Set your Compose image to `ghcr.io/charya-s/daylist:1.3.0`, keep your existing settings and data volume, then run:

```sh
docker compose pull
docker compose up -d
```

The database update runs automatically at startup.
