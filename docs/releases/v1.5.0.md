# Daylist v1.5.0

- Delete tasks, subtasks, and folders with visible trash icons; restore them from Trash if needed.
- Drag tasks into your preferred order within folders, with touch and keyboard support.
- View task deadlines in a monthly calendar with folder filtering and a mobile agenda.

## Upgrade

Use `ghcr.io/charya-s/daylist:1.5.0` or keep `:latest`, then run:

```sh
docker compose pull
docker compose up -d
```

Keep your existing settings and data volume. The database update runs at startup.
