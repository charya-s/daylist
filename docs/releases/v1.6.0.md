# Daylist v1.6.0

- Choose the original Default theme or six color palettes, with Light, Dark, and System modes.
- Drag task rows in All, Today, and folders. Drop dated tasks into No date in All or a folder to clear their deadlines.
- Create reusable folder templates, edit their tasks and subtasks, and start new folders from them.
- Refined the folder dialog and Templates layout.

## Upgrade

Use `ghcr.io/charya-s/daylist:1.6.0` or keep `:latest`, then run:

```sh
docker compose pull
docker compose up -d
```

Keep your existing settings and data volume. The database update runs at startup.
