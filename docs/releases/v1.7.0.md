# Daylist v1.7.0

- Create reusable task templates with notes, priority, and subtasks, or save an existing task as a template.
- Edit folder and task templates in a regular task list with a detail panel and one aligned Save template button.
- Rename Matrix quadrant titles in place, with names saved privately to your account. Default titles now use the standard importance and urgency labels.
- Find Templates near the bottom of the sidebar, above Completed.

## Upgrade

Use `ghcr.io/charya-s/daylist:1.7.0` or keep `:latest`, then run:

```sh
docker compose pull
docker compose up -d
```

Keep your existing settings and data volume. The database update runs at startup.
